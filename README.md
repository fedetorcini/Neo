# Neo

Proyecto Unity 2D en español para aprender a organizar, documentar y ampliar un juego existente. Neo es la base del trabajo; `SampleScene` conserva el prototipo original como referencia.

La entrega actual es la primera sala reconstruida. Su funcionamiento, herramientas y validación están en [docs/REPARACION_PASO_01.md](docs/REPARACION_PASO_01.md). El alcance de la demo completa está en [docs/DEMO_NIVEL_1.md](docs/DEMO_NIVEL_1.md).

Para probarla en el Editor, abre `Assets/Scenes/DemoMenu.unity` y entra en Play. El menú carga `DemoLevel1`; `SampleScene` sigue disponible como escena del prototipo. En una build, `DemoMenu` es la primera escena de Build Settings.
